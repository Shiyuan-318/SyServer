关于模组生存服

模组生存服由原 Vanilla Land 服务器升级而来，现以 SyServer 模组生存服的身份重新出发。服务器基于 Java 1.21.1 运行，在经典生存玩法的基础上加入丰富的模组内容，带来全新的探索、建造与冒险体验。

进入本服无需安装模组客户端，使用 Java 1.21.1 客户端即可直接进入游玩。更多玩法介绍与最新动态请加入 QQ 群了解，我们期待与你一起开启模组生存之旅。

1

准备客户端

安装 Java 1.21.1 版本的客户端即可，无需模组端。

2

添加服务器

在多人游戏中添加服务器，地址填入 mc9.rhymc.com:50002。

3

开始游戏

进入服务器，与好友一起开启属于你的模组生存冒险。
