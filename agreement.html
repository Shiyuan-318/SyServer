《SyServer 隐私政策》

生效日期：2026 年 7 月 16 日

最后更新日期：2026 年 7 月 16 日

一、引言

SyServer（以下简称"本服务器"）由服务器管理团队直接运营，致力于为玩家提供公平、透明的 Minecraft 多人游戏环境。本隐私政策说明我们收集哪些信息、如何使用与保护这些信息，以及您享有的权利。连接并游玩本服务器，即表示您同意本政策内容。

二、我们收集的信息

2.1 账户与认证信息

Minecraft 正版信息：用户名（ID）、UUID，用于身份验证及与 Mojang/Microsoft 正版验证服务器通信。

注册信息：若使用 AuthMe 等登录插件，您提供的用户名、密码（加密存储）、邮箱（用于找回密码验证码）。

IP 地址：用于连接服务器、反作弊、防止恶意攻击及网络问题排查。

2.2 游戏行为数据

位置与建筑数据：游戏内坐标、领地（Claim）信息、Home 传送点设置、背包与末影箱物品数据。

经济系统数据：游戏币余额、银行存取记录、公会资产、交易记录、拍卖行历史。

交互记录：聊天记录、私聊内容、邮件系统内容、指令使用日志。

活动日志：登录/登出时间、游戏时长、死亡记录、PVP 战绩、任务进度。

2.3 安全与审计数据（公开查询说明）

CoreProtect 方块记录：本服务器使用 CoreProtect 记录方块放置、破坏及容器操作日志。为提升透明度与便利纠纷自查，服务器允许所有玩家通过 CoreProtect 指令自行查询方块放置/破坏记录。该记录可能包含操作者用户名、操作时间、坐标及方块类型。

反作弊数据：鼠标点击频率、移动轨迹异常检测、自动化行为判定记录。

封禁与处罚记录：违规类型、处罚时长、申诉沟通记录。

2.4 皮肤与外观数据

本服务器支持通过游戏内床图系统更改和自定义皮肤外观。

本服务器不支持第三方皮肤站（如 LittleSkin 等），也不依赖外部皮肤 API 服务获取皮肤纹理。

2.5 网站与 API 相关数据（如适用）

访问 syserver.sy1.top 时的浏览器类型、访问时间、页面浏览记录。

通过开放 API 查询游戏数据时的请求日志。

三、信息使用目的

我们收集信息仅用于：

1. 服务器运营：维持游戏世界运行、数据存档、地图备份。

2. 身份验证：确认玩家身份，防止账号盗用。

3. 安全防护：反作弊、反恶意攻击、追查恶意破坏。

4. 纠纷处理：利用 CoreProtect 调查盗窃、恶意破坏；玩家亦可自助查询方块记录辅助举证。

5. 社区管理：执行服务器规则、实施处罚、处理申诉。

6. 功能实现：经济系统、公会系统、家园系统、床图皮肤系统等插件正常运作。

7. 服务优化：分析玩家活跃度，优化服务器配置与 TPS 性能。

四、信息存储与保护

4.1 存储方式

游戏数据存储于服务器本地磁盘及定期备份文件中。

认证信息（密码）采用加密方式存储，明文密码不会被记录。

日志文件保留期限一般为 30-90 天，CoreProtect 数据库根据存储空间情况定期轮转。

4.2 安全措施

服务器部署于受限制访问的网络环境中。

定期执行本地备份，防止数据丢失。

管理员访问数据遵循最小权限原则。

五、信息共享与披露

我们不会出售您的个人信息。仅在以下情形中可能共享或披露：

1. 与 Mojang/Microsoft：正版验证时向 Mojang API 发送必要的 UUID 与用户名信息。

2. 法律要求：根据法律法规、法院命令或政府主管部门要求，必须提供相关数据。

3. 权益保护：为维护服务器、其他玩家或公众的合法权益，在必要范围内披露。

六、第三方服务

本服务器使用的第三方服务受其各自隐私政策约束：

Mojang Studios / Microsoft：正版验证与账户服务。

AuthMe 等插件：认证与权限管理。

CoreProtect：行为审计与日志记录（本服务器内查询结果对玩家公开可见）。

七、您的权利

若您未满 18 周岁，建议在监护人指导下使用本服务器。我们不会主动收集未成年人的个人敏感信息。
