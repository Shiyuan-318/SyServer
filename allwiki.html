入门指引

欢迎来到 SyServer！这里将带你从零开始，一步步了解如何加入并畅玩我们的服务器。

1. 获取服务器地址

服务器地址为 sy1.top。在 Minecraft 多人游戏界面点击「添加服务器」，输入该地址即可。

2. 选择合适的版本

服务器支持 1.8 - 26.1.1 版本进服，但强烈推荐使用 1.21.11 以获得最佳体验。请勿使用 26.x 版本，可能无法正常移动。

3. 第一次进服

首次进入服务器需要注册账号，注册成功后即可开始游玩。详细步骤见下方「注册与登录」。

注册与登录

SyServer 使用账号密码登录系统，确保你的游戏身份安全。首次加服请务必仔细阅读本节。

注册账号

第一次进入服务器时需要注册，您需要在输入框输入您的密码。

  • 在聊天输入框中输入您想设置的密码即可完成注册
  • 请打字快一点，避免登录超时被踢出
  • 建议使用复杂密码，避免被他人盗用

登录账号

每次加入服务器都需要登录，您需要在输入框输入您的密码。

  • 在聊天输入框中输入您注册时设置的密码
  • 登录成功后即可自由移动
💡
小贴士：如果忘记密码，请在 QQ 群内联系管理员重置。切勿将密码告诉他人。

支持版本

SyServer 兼容多个 Minecraft 版本，让你和朋友都能畅快游玩。

版本范围 推荐程度 说明
1.21.11 强烈推荐 最佳体验版本，所有功能正常
1.8 - 1.20.x 可游玩 部分新内容可能无法显示
1.21.x（除 1.21.11） 可游玩 体验良好，建议优先选择 1.21.11
26.x 不建议 可能出现无法移动等问题

经济系统

SyServer 拥有完善的经济系统，你可以通过游玩、出售物品等方式获取金币，并用金币购买所需物品。

查询余额

/money

查看自己当前持有的 Scoin 数量。

转账给其他玩家

/pay <玩家> <金额>

将金币转给其他玩家，例如 /pay Steve 100 表示给 Steve 转 100 金币。

查看财富排行

/baltop

查看服务器金币排行榜，看看谁是真正的「富翁」。

获取金币的方式

  • 出售物品给系统商店
  • 在玩家商店出售商品
  • 参与服务器举办的活动
  • 签到与每日任务
  • 击杀怪物掉落的金币

传送指令

服务器使用 SyTP 传送插件，支持传送请求、传送费用、传送延迟和粒子效果。

指令 说明
/tpa <玩家> 请求传送到指定玩家身边，需对方同意
/tpc <玩家> 请求对方传送到你身边
/tpw 邀请服务器所有玩家传送到你身边
/tpaccept 接受传送请求
/tpdeny 拒绝传送请求

传送机制

  • 传送费用：TPA、TPC 和 TPW 均花费 1 Scoin（SyServer 游戏币）
  • 传送延迟：发起传送后有 3 秒等待时间，期间移动会取消传送
  • 请求超时：传送请求有 30 秒有效期，超时未响应将自动取消
  • 传送冷却：传送完成后有 10 秒冷却时间
  • 粒子效果：传送完成时会有粒子特效
💡
小贴士：管理员可以无视传送费用和传送延迟。传送请求会弹出 GUI 界面，点击即可接受或拒绝。

家与传送点

设置个人「家」，方便快速回到自己的基地。

设置家

/sethome <名称>

将当前位置保存为一个家，例如 /sethome base。

回到家

/home <名称>

传送到你设置的家。直接输入 /home 可查看所有家的列表。

删除家

/delhome <名称>

删除不再需要的家。

💡
小贴士：您可以把set home当做传送点使用。

领地保护

使用 Residence 插件保护你的建筑和箱子不被他人破坏或盗取。

创建领地

使用木锄头圈地：

  1. 手持木锄头，右键点击第一个角点
  2. 走到对角线位置，再次右键点击
  3. 输入 /res create <名称> 创建领地

常用领地指令

指令 说明
/res create <名称> 创建领地
/res remove <名称> 删除领地
/res set 打开领地权限设置 GUI
/res pset <领地> <玩家> <权限> <值> 设置指定玩家在领地的权限
/res tp <名称> 传送到自己的领地
/res list 查看自己所有领地
/res info <名称> 查看领地详细信息

生存服玩法

原汁原味的 Minecraft 生存体验，加入了丰富的扩展内容让游戏更有趣。

核心玩法

  • 自由建造：在世界中任意位置建造你的家园
  • 资源采集：挖矿、伐木、种植，收集各种原材料
  • 怪物战斗：夜晚出现的怪物会掉落稀有物品
  • 红石科技：利用红石电路构建自动化装置
  • 附魔装备：在附魔台或铁砧上强化你的工具和武器

扩展内容

  • 更多附魔：服务器安装了 ExcellentEnchants 插件，提供 78 种扩展附魔，详见附魔列表
  • 玩家商店：可以建立自己的商店出售物品
  • 领地系统：保护你的建筑不被破坏
  • 经济系统：完整的金币流通体系

新手建议

  1. 进服后先熟悉服务器各项功能
  2. 找一块空地建立自己的小基地
  3. 先用木锄头圈好领地，防止他人破坏
  4. 通过挖矿和打怪积累初始资金
  5. 逐步扩展基地，提升装备和附魔等级

起床战争

经典的小游戏玩法，与朋友组队对抗，保护自己的床并摧毁敌人的床。

玩法规则

  • 每位玩家出生在自己的岛屿上
  • 岛屿上有一张床，床存在时玩家可无限复活
  • 床被摧毁后，玩家将无法复活
  • 最后存活的队伍获胜
  • 通过购买装备和道具提升战斗力

加入方法

在 Minecraft 多人游戏界面点击「添加服务器」，输入起床服地址：

mc1-v4.msst2031.cn

新手技巧

  • 优先用方块搭桥到中央资源点
  • 购买羊毛或防爆方块保护自己的床
  • 积累绿宝石购买强力装备
  • 团队协作，分工防御与进攻
  • 注意防范敌人的偷袭

附魔系统

SyServer 通过 ExcellentEnchants 插件大幅扩展了原版附魔，提供 78 种全新附魔效果。

附魔获取方式

  • 附魔台：消耗经验和青金石，随机获得附魔（主要物品）
  • 铁砧 + 附魔书：将附魔书应用到装备上（包括次要物品）
  • 战利品：击杀怪物或开宝箱有概率获得已附魔的装备
  • 交易：与村民交易获取附魔书

附魔属性说明

  • 最大等级：附魔可达到的最高等级
  • 主要物品：可在附魔台获得的物品类型
  • 次要物品：只能通过铁砧 + 附魔书获得的物品类型
  • 权重：附魔被提供的相对概率，数值越低越稀有
  • 不兼容：无法同时存在于同一物品上的附魔
📖
完整的附魔列表（共 78 个）请查看更多附魔页面。

商店系统

通过商店系统买卖物品，是获取和流通金币的重要途径。

系统商店

服务器设有系统商店，可使用指令快速打开：

/shop

系统商店提供基础物品的买卖服务，价格固定。

创建玩家商店

放置一个箱子，然后使用以下指令创建商店：

/shop create <买入价> <卖出价>
  • 需要手持你要出售的物品
  • 买入价是别人买你物品时付的钱
  • 卖出价是别人把物品卖给你时收的钱
  • 价格设为 0 表示关闭该方向交易

管理商店

指令 说明
/shop list 查看自己所有的商店
/shop remove 删除指定的商店
/shop price <新价格> 修改商店价格

常见问题

汇总玩家最常遇到的问题，帮你快速解决疑惑。

+ 无法移动是什么原因？

请确认您是否已成功登录或注册。另外请使用 1.21.11 进服，不要使用 26.x 版本，否则可能出现无法移动的问题。

+ 忘记密码怎么办？

请在 QQ 群内联系管理员，提供你的游戏 ID，管理员会帮你重置密码。请勿在游戏内随意将密码告诉他人。

+ 如何切换到起床战争服？

在 Minecraft 多人游戏界面添加服务器地址 mc1-v4.msst2031.cn 即可加入。

+ 怎么保护自己的建筑不被破坏？

使用木锄头圈出领地范围，再用 /res create <名称> 创建领地。详细操作见上方「领地保护」章节。

+ 金币不够用怎么办？

可以通过出售物品给系统商店、建立玩家商店、参与服务器活动、完成签到任务或击杀怪物等方式获取金币。

+ 服务器支持基岩版吗？

目前服务器主要面向 Java 版玩家。基岩版的支持情况请关注 QQ 群公告获取最新信息。

错误排查

遇到连接或游戏问题？对照下面的常见错误进行排查。

1. Internal Exception: java.io.IOException: An existing connection was forcibly closed by the remote host

连接被服务器强制关闭。

解决方法：重启客户端再次尝试连接。如反复出现，请检查网络是否稳定。

2. Connection refused: no further information / Unknown host

无法连接到服务器。

解决方法：检查服务器 IP 输入是否正确，正确地址为 sy1.top，注意没有空格和多余字符。

3. Connection timed out / Read timed out

连接超时。

解决方法：网络卡顿导致，请更换网络（如切换 WiFi / 4G），或离路由器近一点再尝试。

4. 无法注册或登录

注册或登录时输入密码无响应。

解决方法：请确认已在聊天输入框中输入您的密码。如仍有问题，请询问任意 AI：「Minecraft 服务器无法注册怎么办，请一步步教我」。

5. 进服后看不到任何建筑

进入服务器后画面是空的。

解决方法：可能是资源加载延迟，请稍等片刻。如果长时间无法加载，尝试调低渲染距离或重启客户端。
